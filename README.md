# Clima Ideal — landing page demonstrativa

Este é um projeto fictício para portfólio. "Clima Ideal" não representa uma empresa real; textos, identidade visual e exemplos devem ser adaptados antes de qualquer uso comercial.

## Arquivos
- `index.html`: estrutura, conteúdo, ícones SVG, menu mobile e configuração do WhatsApp.
- `styles.css`: estilos responsivos.

## Testar localmente
1. Extraia a pasta/ZIP.
2. Abra `index.html` no navegador.
3. Confira as seções, menu mobile, perguntas frequentes e links.
4. O botão do WhatsApp fica em modo de demonstração até você configurar o número.

## Configurar WhatsApp
No fim do arquivo `index.html`, procure:
`const WHATSAPP_NUMBER = "5500000000000";`

Substitua pelo número autorizado da empresa, apenas dígitos, incluindo código do país (55), DDD e número. Não use espaços, `+`, parênteses ou traços. Por exemplo, `55` + DDD + número real. Não use um número de exemplo.

Edite também `DEFAULT_MESSAGE`. Os links de serviço preenchem uma mensagem correspondente quando o número estiver válido.

## Publicar gratuitamente com GitHub Pages
1. Crie uma conta no GitHub, se ainda não tiver.
2. Crie um repositório novo, por exemplo `clima-ideal-demo`.
3. Envie `index.html` e `styles.css` para a raiz do repositório.
4. Abra **Settings → Pages**.
5. Em **Build and deployment**, selecione publicar a partir de uma branch, escolha `main` e `/ (root)` e salve.
6. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages nas configurações.
7. Teste no celular e em outro navegador.

A publicação estática pode ser gratuita; disponibilidade e condições do serviço podem mudar. O endereço será um subdomínio do GitHub, não um domínio próprio. Não há backend nem formulário de coleta neste projeto.

## Checklist antes de usar para um cliente real
- [ ] Substituir nome, marca, textos e metadados.
- [ ] Confirmar região atendida, serviços, horários e canais reais.
- [ ] Configurar e testar o WhatsApp autorizado.
- [ ] Substituir imagens/elementos se o cliente solicitar fotos reais.
- [ ] Não inserir depoimentos, certificações, garantias ou resultados não comprovados.
- [ ] Confirmar autorização para usar marca, fotos e dados.
- [ ] Revisar conteúdo, links, acessibilidade, desempenho e visual mobile.
- [ ] Combinar domínio, hospedagem, manutenção e responsabilidades com o cliente.


## Revisão visual
Logo vetorial redesenhada sem falhas; ícones de instalação, limpeza, manutenção (raio vertical), residencial, comercial e agendamento em SVG com espessura uniforme; numeração dos cartões 01, 02 e 03.
